## 概述
本项目是一个基于命令行的联系人管理系统，使用 C 语言开发。
除了添加、查找、删除和修改联系人等基本功能外，系统还实现了数据的保存与加载功能。

开发本系统的主要目的是为了掌握 C 语言的基础概念，包括数据结构（结构体）、动态内存分配以及文件输入/输出操作。

---

## 核心功能
- 添加联系人
- 查找联系人
- 修改联系人信息
- 删除联系人
- 按分组显示联系人
- 模拟拨号
- 将数据保存至文件
- 启动时加载数据

---

## 功能描述

### 1. 添加联系人
用户可以通过输入姓名、手机号码、家庭电话、工作电话、电子邮箱以及分组信息等详细资料，来注册一个新的联系人。

### 2. 按分组显示
用户可以通过指定分组名称，列出并查看属于该特定分组的所有联系人。

### 3. 模拟拨号
此功能用于模拟向选定的联系人拨打电话。
如果联系人提供了手机号码，系统将模拟拨打手机；否则，系统将按家庭电话、工作电话的顺序依次尝试拨打。

### 4. 修改联系人信息
用户可以选择已注册的联系人，并修改其任一字段中的具体信息。

### 5. 删除联系人
用户可以删除指定的联系人条目。

### 6. 查找联系人
用户可以通过姓名或电话号码来查找已注册的联系人。

### 7. 数据保存与加载
联系人数据可以保存至文件，并在下次启动应用程序时自动加载。 ---

## 数据结构

### `person` 结构体
用于存储单个联系人条目的数据结构。它主要包含以下字段：

- 姓名
- 手机号码
- 住宅电话
- 办公电话
- 电子邮件地址
- 分组

### `contact` 结构体
一个专门用于管理整个联系人集合的结构体。
它负责管理联系人数组、当前条目数量以及数组的当前容量。

---

## 实现亮点

### 动态数组的应用
为了适应不断增加的联系人数量，本程序采用了动态内存分配技术，允许根据需要扩展数组的容量。

### 基于文件存储的数据持久化
程序实现了文件保存功能，以确保数据在程序终止后仍能得以保留。
此外，程序在启动时会自动加载此前保存的数据。

### 多条件搜索
为了提升用户体验，搜索功能不仅支持按姓名查找，还支持按电话号码进行查找。
